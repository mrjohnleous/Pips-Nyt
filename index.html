Logic puzzles

How to play Pips: rules, strategy, and where to practice

A plain-language guide to the domino logic puzzle: what the colored regions mean, how to place tiles with confidence, and a few habits that help you clear the board faster.

Each puzzle gives you a set of dominoes and a grid divided into colored regions. Place every domino so that each region's condition is satisfied at the same time.

The basic rules

Every domino has two halves, and each half shows between zero and six dots, called pips. Your job is to fit all of the supplied dominoes onto the grid so that no cell is left empty and no tile is used twice. The grid is split into colored regions, and each region carries a small label that tells you what the pips inside it must add up to or how they must relate to each other.

Understanding the region conditions

There are only a handful of region types, which is why the pips rules are quick to learn even though the boards can get tricky. Once you can recognize each one at a glance, every puzzle becomes a series of small eliminations.

Region labelWhat it means
Equal signEvery pip value in the region must be the same
Not-equal signEvery pip value in the region must be different
A numberThe pips in the region must add up to exactly that total
Less-than sign with a numberThe total must stay below that number
Greater-than sign with a numberThe total must be above that number
No labelAny pips are allowed, so the region adds no constraint

Boards usually come in easy, medium, and hard versions. The rules never change between them; harder boards simply link more regions together so that one placement affects several others.

A few strategy habits

  • Start with the tightest regions. A region with a total of zero, or a tiny region with a fixed sum, often allows only one tile and gives you a safe first move.
  • Read the whole board before placing anything. Spend the first minute noting which regions look strict and which look loose, then work from strict to loose.
  • Use elimination, not guessing. If a domino cannot satisfy a region, cross it out for that spot. Often only one option survives.
  • Watch where regions meet. A single domino can span two regions, so a tile that fits one condition may quietly break its neighbor.
